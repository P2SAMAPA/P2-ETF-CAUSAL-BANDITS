# P2-ETF-CAUSAL-BANDITS

Welcome to the P2-ETF-CAUSAL-BANDITS repository!

## Description

This project explores the intersection of ETFs (Exchange-Traded Funds) and causal bandit algorithms, providing tools and insights for data-driven decision making in financial contexts.

## Getting Started

### Prerequisites

- Python 3.8 or higher
- Required dependencies (see `requirements.txt`)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/P2SAMAPA/P2-ETF-CAUSAL-BANDITS.git
   cd P2-ETF-CAUSAL-BANDITS
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
